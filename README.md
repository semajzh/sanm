# sanm

需求说明：
1、这是一个模拟3V3战斗的程序。两支队伍，蓝方和红方，每支队伍选用一个阵型，阵型有三个位置，可以上阵三个武将，武将持有战法、韬略、装备，有不同的兵种。
2、战斗采用回合制，两支队伍六名武将按照先攻（速度）顺序依次行动。整场战斗分为几个阶段：组队阶段、战斗准备阶段、战斗阶段、战斗结束阶段；战斗阶段最多八个回合（或一方全灭回合结束），每个回合又分为几个子阶段：回合开始、回合中、回合结束；回合中，六名武将按先攻顺序行动，每个武将行动时又分为几个子阶段：武将行动开始、武将发动主动战法、武将发动普通攻击、武将发动追击战法、武将行动结束。武将间互相攻击造成伤害，减少对方兵力，兵力为0时阵亡。
3、兵力：初始10000，受到伤害后1/5阵亡变成死兵，4/5变成伤兵，伤兵可以被治疗，死兵不可以被治疗。
4、兵种：弓、盾、骑、枪，有克制关系，盾兵克弓兵、弓兵克枪兵、枪兵克骑兵、骑兵克盾兵，克制时造成的伤害提高15%，被克制时造成的伤害降低15%。
5、伤害：类型包括兵刃伤害（物理）、谋略伤害（法术）、逃兵伤害（真伤）、传递伤害（A受到伤害后，其队友受到固定比例的伤害）。
6、武将：三国武将，包括魏蜀吴群四个阵营，有武力、智力、统率、先攻四个属性，属性基础值和成长值各不相同（只关注50级的最终属性值），50级满级时有额外50点自由属性点，可以加在任意四个属性上。除此之外还有其他属性：性别、兵力、会心率（物理暴击几率、暴击后造成1.5倍的伤害）、会心伤害（在初始0.5，即暴击后造成1+0.5的伤害）、奇谋率（谋略暴击几率、暴击后造成1.5倍的伤害）、奇谋伤害（在初始0.5，即暴击后造成1+0.5的伤害）、主动技能几率（提高主动技能的发动几率）、追击率（提高追击技能的发动几率）、连击率（二次普通攻击的几率）、闪避率（闪避攻击的几率）、反击率（反击普通攻击的几率）、倒戈率（根据兵刃伤害的一定比例恢复兵力）、攻心率（根据谋略伤害的一定比例恢复兵力）、破甲率（无视统率的比率）、看破率（无视智力的比率）、增伤率（造成的伤害增加一定比率，可以是负数，详见伤害公式）、减伤率（收到的伤害减少一定比率，可以是正数，详见伤害公式）。
7、普攻：普通攻击，在普通攻击阶段100%发动，正常一个回合只能发动一次，但连击判定成功后可额外发动一次，连击只能多发动一次普通，其他战法可能发动多次普攻。反击是一种强力的普攻，在受到对方普通攻击时有一定几率反击，反击每回合最多发动5次。
8、战法：包括指挥（在战斗准备阶段发动）、被动（在战斗准备阶段发动）、主动（在武将行动主动阶段发动）、追击（在普通攻击成功之后发动）几种类型。每个武将佩戴三个战法，武将自带一个战法，可任选两个其他战法。指挥战法和被动战法100%发动，主动战法和追击战法有一定的基础发动几率，主动战法分为普通主动战法和准备战法，准备战法首次发动时（也需要判定发动率）不触发战法效果，下一个回合行动时（无需判定发动率）触发战法效果。
9、韬略：在战斗准备阶段发动，每个武将佩戴三个韬略，武将可以佩戴自身的金韬略，和另外两个通用韬略，也可以佩戴三个通用韬略。
10、装备：有属性加成，也有特技和特效，但特技和特效现在没实现。
11、阵型：站位分前排和后排，各有不同的受击率（被战法选中的几率），还有一些属性加成效果。包括一字阵（前33%、前34%、前33%，所有武将受到的伤害降低8%）、箕形阵（前60%、后20%、后20%，前排受到的伤害减低6%，后排造成的伤害提高12%）、雁形阵（后20%、前40%、前40%，前排造成的伤害提高15%，后排统率提高20）、方圆阵（前40%、前40%、后20%，前排收到的伤害减少5%，后排连击率增加40%）、锥形阵（后20%、前60%、后20%，前排造成的伤害增加16%，后排受到的伤害减少5%）、鱼鳞阵（前60%、后20%、后20%，前排闪避率增加12%，后排会心/奇谋率增加8%）、钩形阵（后20%、后20%、前60%，后排连击率增加25%，前排受到的伤害减少8%）、偃月阵（前40%、后20%、前40%，前排造成的伤害增加14%，后排受到的伤害减少5%）。
12、星级：0~5星，武将和战法都有星级，武将每多一个星级增加10点自由属性点，最多5星50个自由属性点；武将每多一个星级，自带战法的数值会增加（具体增加规律参考代码），战法的星级效果也一样。
13、缘分：多名武将同时上阵会触发缘分效果，每个缘分会指定触发人数。
14、状态：包括增益状态和负面状态。增益状态分为常规增益状态、功能性增益状态。常规增益状态包括：会心、奇谋、破甲、看破、倒戈、攻心、连击、反击、规避，以及某些战法产生的增益（包括但不限于：造成伤害提升、受到伤害降低、属性提升等），功能性增益状态包括：清醒、抵御、必中、破御、伏兵，以及某些战法产生的功能性增益（包括但不限于：布阵、整备、列阵等）。负面状态分为异常状态、常规负面状态。异常状态分为非控制状态、控制状态。 非控制状态包括：洪水、火攻、风暴、畏惧、妖术；控制状态包括：震慑、缴械、技穷、混乱、嘲讽、虚弱、断粮。常规负面状态包括：焚烧、鸩毒，以及某些战法产生的负面（包括但不限于：造成伤害降低、受到伤害提升、属性降低等）。具体状态描述详见附录。

设计思路：
1、武将、战法、韬略ID设计：武将ID有5位数，第1位是阵营（1魏 2蜀 3吴 4群），第2、3位是赛季（第几赛季出的武将）、第4、5位是序号；战法的ID有7位，武将自带战法的前5位与武将相同，第6、7位是战法类型（20被动 21指挥 22主动 24追击），通用战法的前5位定义与武将大体相同，第1位阵营位是0；韬略的ID有6位，武将自带金韬略的前5位与武将相同，第6位是序号；通用韬略ID有5位数，前2位是赛季，后3位是序号。下面附录中有ID对照表。
2、状态设计：Ground类的buff成员有8中类型，buff[0]：单纯的属性加成buff，被添加buff时enter，持续到战斗结束；buff[1]：持续一定回合，被添加buff时enter，武将行动开始阶段判定回合数，如果回合数为0则buff消失；buff[2]：武将回合行动开始阶段执行run；buff[3]：可以在任意时间点执行run；buff[4]：回合结束阶段执行run；buff[5]：回合开始阶段执行run；buff[6]：持续一定回合，回合结束阶段判定回合数，如果回合数为0则buff消失；buff[7]：回合开始阶段enter，回合结束阶段执行run；buff[8]：持续一定回合，回合结束阶段判定回合数，如果回合数为0则buff消失，武将行动结束阶段执行run；

看破	常规	造成谋略伤害时，无视目标部分智力

必中	功能性	造成的伤害无法被规避
破御	功能性	造成的伤害无法被抵御
伏兵	功能性	受到伤害时，消耗伏兵抵挡部分伤害，并对伤害来源造成「逃兵」
不屈	功能性	周泰战法效果（非通用状态词条），免疫 1 次致命伤害
